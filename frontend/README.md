# Milking Tracker Frontend

Next.js frontend for the Milking Tracker assignment. It uses the App Router,
strict TypeScript, Tailwind CSS, shadcn/ui, and Motion.

## Local development

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:9040](http://localhost:9040).

Create `.env.local` from `.env.example` when the frontend API integration is added.

## Checks

```bash
npm run lint
npm run typecheck
npm run build
```
